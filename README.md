# TODAY

Локальный рабочий кокпит и внешняя оперативная память: текущий фокус, контекст переключений, горизонты «Сегодня / Неделя / Пул» и спокойный архив завершённого.

## Открыть в Chrome без терминала

Проект подготовлен к автоматической публикации через **GitHub Pages**. После
первого включения Pages каждый следующий коммит публикуется самостоятельно.

1. Откройте репозиторий проекта на GitHub.
2. Нажмите **Settings → Pages**.
3. В блоке **Build and deployment → Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions**, выберите **Publish TODAY** и дождитесь зелёной
   галочки (обычно 1–2 минуты).
5. Обычная ссылка появится на странице этого запуска и в **Settings → Pages**.
   Она будет выглядеть как `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

После этого приложение открывается в Chrome как обычный сайт. Backend и аккаунт
в самом приложении не нужны. Данные задач хранятся только в `localStorage`
конкретного браузера, поэтому Chrome на другом компьютере будет иметь свой
отдельный список задач.

> Важно: репозиторий в текущем рабочем окружении не связан с GitHub-аккаунтом,
> поэтому автоматически определить итоговый адрес невозможно. Единственная
> настройка со стороны владельца — один раз выбрать **GitHub Actions** на шаге 3.

## Локальный запуск для разработчика

```bash
npm install
npm run dev
```

Откройте <http://localhost:5173>. Все данные остаются в `localStorage` браузера.
