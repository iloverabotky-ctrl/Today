# TODAY

Локальный рабочий кокпит и внешняя оперативная память: текущий фокус, контекст переключений, горизонты «Сегодня / Неделя / Пул» и спокойный архив завершённого.

## Открыть в Chrome без терминала

Проект автоматически публикуется через **GitHub Pages**. Workflow сам пытается
включить Pages при первом запуске, а затем публикует каждый следующий коммит.

1. Нажмите **Actions** → **Publish TODAY**.
2. Нажмите **Run workflow** → зелёную кнопку **Run workflow**.
3. Дождитесь зелёной галочки (обычно 1–2 минуты).
4. Нажмите **Settings** → **Pages** → **Visit site**.
5. Если запуск попросил включить Pages: нажмите **Settings** → **Pages** → в
   поле **Source** выберите **GitHub Actions** → вернитесь в **Actions** →
   **Publish TODAY** → **Run workflow**.
6. Обычная ссылка также появится на странице запуска **Publish TODAY**.
   Она будет выглядеть как `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

После этого приложение открывается в Chrome как обычный сайт. Backend и аккаунт
в самом приложении не нужны. Данные задач хранятся только в `localStorage`
конкретного браузера, поэтому Chrome на другом компьютере будет иметь свой
отдельный список задач.

> Итоговый адрес зависит от логина владельца и имени репозитория. Он появляется
> в **Settings → Pages** сразу после первого успешного запуска публикации.

## Локальный запуск для разработчика

```bash
npm install
npm run dev
```

Откройте <http://localhost:5173>. Все данные остаются в `localStorage` браузера.
